# Product vision

## Intended experience

Customers can ask natural-language furniture and support questions on WhatsApp.
The assistant should help narrow choices using verified descriptions and public
policies, link to verified product pages, and explain what it cannot confirm.

## Product principles

- Accuracy before fluency: never fabricate a commercial fact.
- Evidence before recommendations: show source links when facts are supported.
- Privacy by default: keep each customer's history and account data isolated.
- Honest capability limits: explain unavailable actions without pretending success.
- Accessible communication: use clear, concise language and manageable messages.
- Safe assistance: no purchases during investigation and no unauthorized actions.

## Conditional future outcomes

| Outcome | Dependency |
| --- | --- |
| Useful furniture discovery | Verified public catalogue sources and retrieval quality |
| Reliable support answers | Approved, current public policy sources |
| Private order assistance | Explicit authorized integration and customer authorization |
| Human escalation | Verified channel, consent rules, staffing and ownership |

## Success criteria to define before launch

Measure supported-answer accuracy, source coverage, stale-data handling, retrieval
quality, response time, duplicate-message handling, and fallback usefulness.
Privacy and authorization tests must show no cross-customer disclosure. Exact
thresholds, evaluation datasets, operating cost limits, and support ownership
remain open; production readiness must not be claimed before these are agreed.

## Excluded promises

No assumption of complete catalogue coverage, real-time stock, guaranteed prices,
guaranteed delivery dates, private order access, or autonomous checkout.
